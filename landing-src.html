01 / CONTROL CENTER

Install once.
Never fight dependencies again.

Every server is isolated by construction, supervised by a real process manager, and reachable through one protocol. The boring parts are handled — the interesting parts are yours.

LOCAL PROXY

Every provider. One localhost endpoint.

OpenAI, Anthropic, DeepSeek, Qwen and Kimi behind a single OpenAI-compatible endpoint on :8787 — with a local API key, provider fallback and a live request log. Point any tool at it and stop juggling five SDKs.

CLI SYNC

02 / MANAGER MCP

The manager is
an MCP server.

Not a chat widget bolted on the side — the manager itself speaks the Model Context Protocol. Any MCP host can read your stack, scaffold new servers, patch existing ones and retire them safely, live, while you watch. Every contract is Pydantic-validated before it touches disk.

01
mcp_creation_guide

Hands the agent the full blueprint — folder layout, manifest schema, transport rules and conventions — before it writes a single file.

02
mcp_creator

Scaffolds a working server with tools and schemas into its own isolated environment, ready to start.

03
mcp_modifier

Patches tools, schemas and configuration of an existing server — validated, versioned, reversible.

04
mcp_destroyer

Retires a server cleanly: process stopped, environment removed, registry updated. No orphans.

05
extended_mcp_servers

Discovery — lets an agent list servers it doesn't have yet, read their tool surface, and connect instead of reinventing.

// Paste into any MCP host — Claude Code,
// Codex, Gemini CLI, OpenCode, Droid…
{
  "mcpServers": {
    "soloman-manager": {
      "command": "soloman-manager",
      "args": ["mcp", "serve"]
    }
  }
}
